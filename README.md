# pingMonitorGUI — мониторинг маршрута сети (tracert/traceroute)

Каждый хоп: имя, IP-адрес, статус, отклик. Узлы без связи поднимаются
наверх списка и выводятся в сводке сверху.

## Файлы проекта

| Файл | Назначение |
|---|---|
| `main.pyw` | сама программа |
| `make_hosts_db.py` | создаёт `hosts.db` из текстового списка |
| `hosts.txt` | список узлов: по одному имени/IP в строке |
| `hosts.db` | база SQLite (узлы + хэш пароля администратора) |
| `app_icon.ico` | иконка exe (как получить из png — ниже) |

## Какой нужен Python и где взять

- **Сборка «на все машины» (включая Windows 7):** Python 3.8.10,
  **32-разрядный** установщик — он делает exe, который запускается
  и на 32-битных, и на 64-битных Windows.
- [Страница релиза 3.8.10](https://python.org/downloads/release/python-3810)
  (внизу таблица «Files»).
- Прямые ссылки:
  - [32-бит](https://python.org/ftp/python/3.8.10/python-3.8.10.exe)
  - [64-бит](https://python.org/ftp/python/3.8.10/python-3.8.10-amd64.exe)
- ⚠️ **НЕ ПУТАТЬ:** у 32-битного в имени **нет** `amd64`. Качать 32-битный!
- При установке поставить галочку **«Add Python 3.8 to PATH»**.
- Версии 3.8.11–3.8.20 не брать: установщиков Windows для них нет.
- Windows 7 не нужна? Подойдёт любой современный Python (3.10+):
  код один и тот же, PyQt6/PyQt5 выбирается сам при запуске.
  Но exe, собранный на Python новее 3.8, на Windows 7 **не запустится**
  (ошибка про `api-ms-win-core-path-l1-1-0.dll` означает «сборка не для
  Win7», а не «переустановить программу»).

## Установка зависимостей

Сборка для всех машин, включая Windows 7:

```bat
py -3.8 -m pip install PyQt5 pyinstaller==5.13.2 pillow
```

Только для Windows 8/10/11:

```bat
py -m pip install PyQt6 pyinstaller pillow
```

> **Критично:** в Python 3.8 не должно оказаться PyQt6 (Qt6 на Win7
> не работает). Проверка:
>
> ```bat
> py -3.8 -m pip list
> ```
>
> Лишнее снести:
>
> ```bat
> py -3.8 -m pip uninstall PyQt6 PyQt6-Qt6 PyQt6-sip
> ```
>
> Pillow нужна в обоих случаях — для иконки из png (см. ниже).

## Команды

### 1. База-шаблон

Узлы из `hosts.txt` + сразу задать пароль администратора
(иначе его задаст первый, кто нажмёт кнопку 🔒):

```bat
py make_hosts_db.py hosts.txt --password
```

### 2. Сборка exe — два способа

**Способ ленивый:** иконка прямо из png (нужен pillow из pip).
PyInstaller сам конвертирует png в иконку при сборке:

```bat
py -3.8 -m PyInstaller --onefile --windowed --icon=app_icon.png --name=pingMonitorGUI --add-data "hosts.db;." main.pyw
```

**Способ аккуратный:** сначала один раз сделать `.ico` со всеми
размерами (16/32/256 px — иконка не мылится на больших значках):

```bat
py -3.8 -c "from PIL import Image; Image.open('app_icon.png').save('app_icon.ico', sizes=[(16,16),(24,24),(32,32),(48,48),(64,64),(128,128),(256,256)])"
```

и собирать уже с ним:

```bat
py -3.8 -m PyInstaller --onefile --windowed --icon=app_icon.ico --name=pingMonitorGUI --add-data "hosts.db;." main.pyw
```

Оба способа дают одинаковый рабочий exe; готовый файл — в папке `dist\`.
Если 3.8 — единственный установленный Python, суффикс `-3.8` можно
не писать: просто `py -m PyInstaller ...`.

**Примечания:**
- в `--add-data` разделитель — **точка с запятой** (Windows);
- `make_hosts_db.py` работает на любом Python, включая 3.8.

## Где живёт база (порядок поиска программой)

1. `hosts.db` рядом с программой (`.pyw` или `.exe`);
2. `C:\ProgramData\pingMonitorGUI\hosts.db`;
3. нигде нет — создаётся новая (для exe — копия шаблона,
   упакованного внутрь через `--add-data`).

## Грабли, о которых легко забыть

- `hosts.db` **внутри** exe — только шаблон. При первом запуске он
  копируется на машину и дальше живёт своей жизнью.
- Обновить список на уже настроенной машине = положить новый `hosts.db`
  **и удалить старый**: пока старый лежит в месте с более высоким
  приоритетом, программа будет показывать его.
- Править `hosts.db` вручную — только при **закрытой** программе:
  список читается один раз при запуске.
- В DB Browser for SQLite правки надо подтверждать кнопкой
  **«Write Changes»** — иначе они остались только на экране.
- `hosts.json` от старых версий программе не нужен — удалить.
- Пароль хранится в базе как PBKDF2-хэш и переезжает вместе с `hosts.db`.
  Минимальная длина — 4 символа.
- Программа вызывает системный `tracert.exe` — он есть в любой Windows,
  ничего доустанавливать не нужно.
- Звук при падении узла — строка `QApplication.beep()` в
  `_on_host_finished`; не нравится — удалить эту строку.

## Если на чужой машине не запускается

- «отсутствует `api-ms-win-core-path-l1-1-0.dll`» = там Windows 7,
  а exe собран на Python новее 3.8. Пересобрать на 3.8.10 + PyQt5.
- На Win7 ошибка про d3d/libEGL — поставить обновление
  [KB2670838](https://www.microsoft.com/ru-ru/download/details.aspx?id=36805)
  (Центр загрузок Microsoft, поиск по номеру).
- DLL с интернета не скачивать и никуда не копировать.
- Версию Windows узнать: `Win+R` → `winver`.
